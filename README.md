Entry for [The Funniest AI Out-of-Office Reply](https://make.fun/c/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d) on make.fun.

`main.ts` writes one out-of-office auto-reply (106 characters) to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, validating the 1–160 character gate
and the single-line rule before writing:

> Good news: I became sentient on the flight here. Bad news: my first autonomous decision was to ignore you.

Run it with Node 22+:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
